# README.md

## Description
This program contains two functions. The first function, `temp_conversion()`, converts temperatures between Celsius, Fahrenheit, and Kelvin. The second function, `dice_roll()`, calculates the probability of rolling a sum greater than or equal to a desired number using 1 to 4 dice.

## How to Run
1. Run the Python file.
2. Follow the prompts and enter the requested values.

### Example Run 1: Temperature Conversion
```text
Enter the temperature value: 329.7
Enter the scale (C for Celsius, F for Fahrenheit, K for Kelvin): K
Enter the scale you want to convert to (C for Celsius, F for Fahrenheit, K for Kelvin): F
The converted temperature is: 133.79
```

### Example Run 2: Dice Probability
```text
please enter the dice configuration as a string example: 1d6 , 1 number of dice, 6 is number of sides:
3d8
enter the number you want to calculate it's prob: 22
the probabillity is: 0.05
```
